# Task 1 Frontend

This React + Vite frontend is the POS interface for Task 1. It expects the Spring Boot backend at `http://localhost:8080/api`.

## Run

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for linting.

See [../README.md](../README.md) for the complete application setup and API documentation.
